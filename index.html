Troubleshooting guide
  • aws: command not found: CLI not installed or not in PATH. Run aws --version.
  • Unable to locate credentials: run aws configure or attach an EC2 IAM role.
  • AccessDenied: the IAM user lacks the needed S3 permission.
  • InvalidAccessKeyId: Access Key ID is wrong or inactive; check IAM.
  • SignatureDoesNotMatch: secret key or configuration is wrong; re-run aws configure.
  • Network failure: check internet access, route table, security group and NACL outbound rules.
  • Wrong Region: check aws configure get region; S3 listing is global, but bucket operations use Regions.
